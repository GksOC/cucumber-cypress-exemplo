# cucumber-cypress-exemplo

Exemplo de automação de testes usando Cypress com Cucumber para estudantes da EBAC.

## 📋 Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn
- Git

## 🚀 Como usar este projeto

### 1. Clone o repositório do website
```bash
git clone https://github.com/EBAC-QE/hub-de-leitura-integrado.git
cd hub-de-leitura-integrado
```

### 2. Inicie a instância
```bash
npm start
```

### 3. Em um novo terminal/powershell, clone o repositório
```bash
git clone https://github.com/GksOC/cucumber-cypress-exemplo.git
cd cucumber-cypress-exemplo
```

### 4. Instale as dependências
```bash
npm install
```

### 5. Execute os testes
```bash
# Executar testes em modo headless
npx cypress run

# Executar testes com interface gráfica
npx cypress open
```
# Excutar testes com tags
```bash
npx cypress run --env tags='@learn'
```

## 🛠 Tecnologias utilizadas

- **Cypress** - Framework de testes E2E
- **Cucumber** - Ferramenta BDD para escrita de cenários
- **JavaScript** - Linguagem de programação
